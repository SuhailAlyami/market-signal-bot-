# وكلاء Gemini داخل المستودع

| الوكيل | متى يعمل | ماذا يفعل |
| --- | --- | --- |
| `gemini-review` | عند فتح PR، أو عند تعليق المالك `/gemini` على أي PR | مراجعة محايدة (دور Goldfish) بتعليق عربي على الـ PR |
| `gemini-weekly-audit` | كل أحد 09:41 بتوقيت الرياض، أو يدوياً | يدقق محوراً واحداً كل أسبوع (البيانات ← التنبيهات ← البحث ← سير العمل ← الاختبارات) ويفتح Issue فيه الملاحظات واقتراح PR واحد |

- المحرك: Gemini CLI من Google، وهو مفتوح المصدر (Apache-2.0)، ويعمل بمفتاح AI Studio المجاني.
- المفتاح: يُقرأ من السر `GEMINI_API_KEY`، وإن لم يوجد فمن `GOOGLE_API_KEY`. إن لم يوجد أي منهما يتخطى الوكيل عمله بدون فشل.
- اختيار النموذج اختياري: متغير المستودع `GEMINI_MODEL`.
- الأمان: خطوة Gemini لا ترى توكن GitHub، وخطوة النشر لا ترى مفتاح Gemini. الوكلاء لا يدفعون كوداً ولا يرسلون Telegram، فالتنفيذ يبقى بقرار المالك.
- الاستهلاك: نحو 2–3 دقائق Actions لكل مراجعة، ونحو 3 دقائق للتدقيق الأسبوعي.
