# ضوابط استمرار البحث والتعميم

هذه تعليمات المالك بتاريخ 2026-10-23، وتُطبَّق على العمل اللاحق:

- تُثبّت فرضية كل تجربة وقواعدها وتقسيم البيانات ومقاييس قبولها في Git قبل قياس النتائج.
- تُحفظ كل تجربة ونتيجتها في GitHub، بما فيها النتائج السلبية، مع المصدر والتواريخ والبصمات وحدود الدليل.
- تظل بيانات التطوير والاختبار المستهلكة موسومة بذلك؛ لا تصبح مستقلة بتغيير الاسم أو إعادة جمع الأيام نفسها.
- لا تتغير بوابات النجاح أو تعريف الحدث والمطابقة بعد رؤية النتائج. لا تُخفّض الشروط لتوليد إشارة.
- لا يكفي نجاح تجربة واحدة للتعميم: يلزم إثبات التحسن على بيانات مستقلة، ثم تكراره وفق خطة مثبتة مسبقًا، واختبار حي في وضع الرصد التجريبي قبل التعميم.
- يُستخدم في الرصد الحي ما كان متاحًا فعليًا لحظة القرار. لا تُسند نسخة OHLC تاريخية منقحة إلى وقت إتاحة نسخة حية أقدم إذا اختلفت النسختان.
- عند نقص البيانات تُحفظ نقطة الاستئناف، ويُبلَّغ المالك بالعينة المطلوبة، ويُنتظر وصولها دون تجارب مكررة تستهلك الرصيد.
- نجاح التثبيت أو اختبارات الكود أو تسجيل البيانات ليس نجاحًا للكشف. الحالة الحالية `NOT_READY`.
- لا صفقات، ولا اشتراكات جديدة، ولا إعادة لاختبارات التنبيه الناجحة. تبقى التغذية والرصد القائمان محفوظين.

بعد تحقق الشروط تُزامن قواعد Python وPine v6 ويُوثّق فرق إتاحة البيانات بين النظام وTradingView؛ لا يُقدَّم ضمان باكتشاف كل انفجار.
