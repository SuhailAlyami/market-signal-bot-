# مسار TradingView المستقل — 29 أكتوبر 2026

المصدر المختار للاستخدام من الهاتف هو بيانات TradingView داخل مؤشر Pine:
tradingview/Suhail_Hunter_ES.pine. لا يحتاج هذا المسار IBKR أو Gateway أو VS Code.
مسار Python القديم محفوظ كمرجع؛ لم يعد مصدرًا مطلوبًا لهذا التشغيل داخل الشارت.
هذا تجهيز للكود، وليس إثبات تفعيل الحساب أو نجاح الكشف.

## الاستخدام
1. افتح SP:SPX بشموع قياسية مدتها دقيقة. المؤشر يرفض الرموز البديلة مثل CFD SPX500.
2. أضف الكود في Pine Editor واحفظه ثم Add to chart. إن لم يظهر المحرر على الهاتف، استخدم واجهة الويب بوضع سطح المكتب؛ توفر المحرر على جهازك لم يُختبر هنا.
3. مساعد ES هو العقد المحدد في إعدادات المؤشر؛ الافتراضي CME_MINI:ESZ2026. حدّثه عند ترحيل العقد، ولا تفترض أن بياناته لحظية أو أن ES1! يعادل العقد نفسه.
4. قبل افتتاح SPX النقدي، استخدم شارت عقد ES نفسه للرصد التمهيدي خلال آسيا ولندن. إشارة ES ليست سعرًا أو صفقة SPX، ولا تحويل آلي بين مستوياتهما.
5. تنبيهات البحث مغلقة افتراضيًا. لاختبارها ورقيًا فقط، فعّل Enable RESEARCH_ONLY alerts وأنشئ تنبيه Any alert() function call واختر Notify on App.
6. بعد تغيير الكود أو المدخلات أعد إنشاء التنبيه: TradingView يحتفظ بنسخة من إعدادات إنشاء التنبيه.
7. تحقق من توفر Technical Alerts في خطتك ومن حالة البيانات لكل من SPX وES. لا تشترِ خطة أو بيانات قبل التأكد من الحاجة والتكلفة.

## حدود التشغيل
- التنبيهات التي أنشأها المستخدم تعمل على خوادم TradingView؛ لا يلزم إبقاء الهاتف أو الكمبيوتر مفتوحًا. لها مدة صلاحية وحدود حسب الحساب.
- الجدول داخل المؤشر يعرض رمز المصدر ووقت الشمعة بالرياض. اختيار REALTIME_USER_DECLARED تصريح يدوي، وليس LIVE_VERIFIED أو تحققًا مستقلًا من وقت تداول المزود.
- اختيار DELAYED يمنع إرسال تنبيهات البحث من الكود. حالة UNVERIFIED تبقى بحثية صراحة.
- لا وقت تداول IBKR أو أسعار خيارات أو سترايكات أو أوامر في هذا المسار.
- نقل المنطق إلى Pine لا يجعله يتعلم ذاتيًا أو يرسل نتائج إلى قاعدة بيانات GitHub. التطوير الآلي مسار منفصل.
- لم يتغير منطق الكشف أو عتباته؛ الجودة تبقى NOT_READY. تنبيهات التطبيق بحثية، ولا يوجد إثبات تسليم فعلي.
- Pine Editor والترجمة لدى TradingView غير متاحين للاختبار من هذه البيئة؛ فحص المصدر وCI لا يثبتان نجاح ترجمة Pine.
- Telegram يحتاج إعداد مسار تسليم منفصل؛ هذه النسخة لا تزعم أن تنبيهات TradingView تصل إلى البوت.
- TradingView لا يقدم API عامًا لقراءة بيانات الشارت بواسطة كود Python؛ لا نستخرج البيانات بطرق غير موثقة.
