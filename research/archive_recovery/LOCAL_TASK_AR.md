# مهمة استعادة الملفات الموجودة فقط

شغّل هذه المهمة في Codex على جهاز Windows الذي جمع جلسات SPX، لا في بيئة سحابية مختلفة.

1. اجلب آخر فرع feat/capitalcom-cfd-research-20261029 قراءةً فقط، واستخرج ملفات research/archive_recovery/ إلى مجلد مؤقت دون تبديل الفرع الحالي أو تغيير عمل المستخدم.
2. حدّد جذر مجلد المشروع أو worktree الذي استُخدم لجمع جلسات20يوليو–14أغسطس. اقرأ توثيق المسارات إن لزم؛ لا تبحث في كامل القرص ولا تقرأ الأسرار أو ملفات إعدادات الحساب. تشمل الأداة مجلد .hunter-state ولا تعبر الوصلات الرمزية.
3. شغّل Python الموجود دون تثبيت جديد:
python recover_spx_archive.py --root "مسار مجلد المشروع" --output "مسار جديد/Suhail_SPX_20sessions_verified.zip"
4. خروج0يعني أن20ملفًا طابقت بصماتها المنشورة وجُمعت. خروج2يعني ملفات مفقودة؛ اعرض التواريخ المفقودة ولا تعوّضها بإعادة تنزيل أو بيانات اصطناعية. الملفات الموجودة ببصمة مختلفة لا تقبل تلقائيًا؛ يحتفظ التقرير بها للتحقيق.
5. لا تشغّل تدريبًا أو اختبارات سوق أو Gateway أو أي تنبيه أو جدولة. لا تغيّر أي بيانات أو إعدادات. أعط المستخدم رابط/مسارZIPالناتج لرفعه إلى هذه المحادثة، مع تقرير المطابقة.

هذه أداة استرجاع وليست كاشفًا، ولا تعني نجاح المشروع أو استمرارية أي عامل. اختبرت الأداة هنا بثلاثة اختبارات اصطناعية لسلامة النقل فقط، ولم تُشغّل على الكمبيوتر الحقيقي من هذه الجلسة. البيانات المستعادة — إذا تطابقت — مستهلكة بحثيًا وتستخدم للتطوير فقط.
